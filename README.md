One-line cat joke entry for make.fun's The One-Line Cat Joke That Lands bounty — a single joke about cats, under 200 characters, with a setup and a turn that lands.

> I asked my cat what she wants. She walked to the full food bowl, meowed, and walked away. Management material.

`main.py` (Python 3, stdlib only) writes the line byte-exact to `entry.txt` in `$MAKEFUN_OUTPUT_DIR` (default `/output`) and prints it. No network, no randomness, deterministic — two runs produce byte-identical output.

## Run it

```sh
python3 main.py
```
